# తప్పిపోయిన బాతుపిల్ల: AI prompts (one picture + one motion prompt per scene)

How to use:
1. Make each picture in any AI image tool (Gemini, Leonardo, Ideogram, Midjourney...) at **9:16 (vertical)**.
2. Use the same tool and keep the **character text exactly the same** in every prompt, so Chinni looks the same in every scene.
   If the tool supports a reference image, give it your best scene 02 picture as the reference for all the others.
3. Optional: put a picture into an image-to-video tool (Kling, Hailuo, Veo...) with the **Motion** line to get a 5-second clip.
4. Save the files as `01.png` ... `11.png` (or `01.mp4` ... for clips) next to `story.txt`.

**Style (add to every prompt):**
`Pixar-style 3D animation, cinematic golden-hour lighting, soft volumetric sun rays, shallow depth of field, warm colours, highly detailed fluffy feathers, emotional, 9:16 vertical`

**Characters (copy exactly):**
- **CHINNI** = `a tiny fluffy yellow duckling with soft downy feathers, a small messy tuft of fluff on top of its head, big round glossy sky-blue eyes, a small rounded orange bill, orange webbed feet`
- **MOTHER** = `a gentle brown mother duck with mottled brown feathers, kind dark eyes, an orange bill and a small blue wing patch`
- **HEN** = `a kind red-brown mother hen in a straw nest with three fluffy yellow chicks`
